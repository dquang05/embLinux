# Chapter 03: File System

## Objectives
- Understand the theoretical foundations of file systems (VFS, Inodes, Allocation, Caching).
- Master the Universal I/O Model (`open`, `read`, `write`, `close`).
- Understand advanced file attributes, Extended Attributes (EA), and Access Control Lists (ACLs).
- Learn how to monitor file events using the `inotify` API.
