# Chapter 01: Linux Basic Knowledge

## Objectives
- Understand the architecture of the Linux Operating System (Monolithic Kernel).
- Differentiate between User Mode and Kernel Mode.
- Understand what a System Call is, why it is necessary, and its underlying mechanism.

## References
- **OSC**: Chapters 1, 2 (OS Overview, System Calls), Chapter 20 (The Linux System).
- **TLPI**: Chapters 1, 2 (History and Core Concepts of Linux).

## Usage Instructions
- Read the detailed theoretical concepts in the `docs/` directory.
- Review and run the practical examples in the `src/` directory.
- Use the `make` command to compile all examples.
